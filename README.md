# 🏥 Sistema de Inventario y POS - Botica Familiar

## 🚀 Requisitos Previos
* Python 3.14.x instalado en el equipo.

## ⚙️ Instrucciones de Instalación y Ejecución

**1. Descomprimir o clonar el proyecto (tanto como el fronted y backend) y abrir la terminal en esta carpeta.**

**2. Crear un entorno virtual:**
* En Windows: `python -m venv .venv`
* En Mac/Linux: `python3 -m venv .venv`

**3. Activar el entorno virtual:**
* En Windows: `.venv\Scripts\activate`
* En Mac/Linux: `source .venv/bin/activate`

**4. Instalar las dependencias:**
```bash
pip install -r requirements.txt
